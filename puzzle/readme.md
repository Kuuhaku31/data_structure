# 九宫格滑块拼图解谜算法

## 程序简介

本程序用于解决经典的**八数码问题**（3x3 拼图问题），采用广度优先搜索（BFS）算法，自动寻找从初始状态到目标状态的最短移动路径，并输出详细的解题步骤和状态映射信息。

---

## 八数码问题简介

八数码问题是一个著名的人工智能和算法问题。它由一个 3x3 的棋盘和 8 个带数字的方块（1~8）及一个空格（用 0 表示）组成。目标是通过移动空格，使棋盘从初始状态变换到目标状态（通常为 `123456780`）。

---

## 程序主要功能

1. **状态表示与操作**

   - 用 `State` 结构体表示 3x3 棋盘的状态。
   - 支持状态的设置、打印、比较、查找空格位置、交换等基本操作。

2. **广度优先搜索（BFS）**

   - 自动搜索从初始状态到目标状态的最短路径。
   - 每次移动记录操作方向和前驱状态，便于路径回溯。

3. **状态去重与映射**

   - 使用哈希表（`StateMap`）存储所有已访问状态，避免重复搜索。
   - 支持状态的快速查找与插入。

4. **路径与结果输出**
   - 搜索成功后，自动回溯并输出每一步的操作和状态。
   - 可将完整路径保存到 `path.txt` 文件。
   - 可将所有状态映射信息保存到 `state_map.txt` 文件。

---

## 主要文件说明

- `header.h`：类型定义、常量、函数声明。
- `puzzle.cpp`：核心算法实现，包括状态操作、BFS、链表与哈希表管理等。
- `main.cpp`：程序入口，负责输入输出、调用 BFS、保存结果等。

---

## 使用方法

1. **运行程序**

```bash

puzzle.exe < 初始状态 > < 目标状态（默认为 123456780） >

```

- 运行后会输出初始状态、目标状态、BFS 搜索进度、最短步数等信息。

2. **查看结果**
   - 路径文件 `path.txt`：详细记录每一步的操作和棋盘状态。
   - 状态映射文件 `state_map.txt`：记录所有访问过的状态及其哈希分布。

## 注意事项

- 本程序采用循环链表和开放寻址哈希表管理状态，适合中等规模八数码问题。
- 若初始状态无解，程序会提示“无法达到目标状态”。
- 若需自定义初始状态，请修改 `main.cpp` 中的 `StateSet(start, "...")`。
